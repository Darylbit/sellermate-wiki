商品利潤

營收是售出商品的金額，不等於利潤。單位估計貢獻 = 售價 − 商品成本 − 平台費 − 每單廣告費 − 其他變動費用。平台費假設按售價計算。估計貢獻率 = 單位估計貢獻 ÷ 售價。例：39−18−3.9−5=12.10，比例31.03%。未扣固定費用及稅，不稱完整會計淨利。

定價與損益平衡

加價率以成本為分母，利潤率以售價為分母。若單位非比例成本為 C、平台費率 f、目標貢獻率 m，最低售價 = C/(1−f−m)，分母必須大於零，向上進位至分。例：C=25、f=10%、m=0，最低 RM27.78。固定成本 RM1200、每單貢獻 RM12.10，損益平衡需100單（向上取整）。

廣告成效

ROAS = 廣告歸因營收 ÷ 廣告支出；CPA = 廣告支出 ÷ 轉換次數。例：RM1000、RM200、20筆購買轉換，ROAS=5倍、CPA=RM10。分母為零時顯示不適用。ROAS 不等於利潤；需確認歸因期間與轉換定義。

商品與 CSV 分析

先統一期間、幣別及欄位，再驗證缺值、負數與重複商品。CSV 是文字表格，須正確處理引號及逗號。本案例使用固定示範資料而非真實營運資料。商品 A 100單×RM39=RM3900；商品 B 150單×RM25=RM3750。比較不能只看營收，也要看貢獻率。

AI Agent 與工具呼叫

模型先判斷需求，再提出結構化工具參數；應用程式執行確定性計算，回傳結果，模型再解釋。例：詢問售價39、成本18、費率10%、廣告5，工具回傳12.10。若缺資料先詢問，不自行捏造。此 Wiki 由對話中的 LLM 整理，網站為靜態教材，不含即時 API。

來源與 ingest 摘要

S01 · Shopify 利潤率

利潤除以營收；毛利、營業利益及淨利的費用範圍不同。

S02 · SBA 損益平衡

固定成本除以單位貢獻，可估計損益平衡銷量。

S03 · Shopify 加價率與利潤率

加價率以成本為分母，利潤率以售價為分母。

S04 · MDN File API

使用者選取檔案後，瀏覽器可讀取內容；讀取不等於完成 CSV 解析。

S05 · Shopify 淨利率

完整淨利必須扣除所有營業及非營業費用和稅。

S06 · Google Ads 平均 CPA

廣告成本除以轉換次數；轉換不一定是訂單。

S07 · OpenAI Function calling

模型提出工具呼叫，應用程式執行並回傳結果給模型。

S08 · Google Ads ROAS

ROAS 關注廣告轉換價值相對於廣告支出。
